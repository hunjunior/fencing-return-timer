Detection settings

Confirmation periods reduce false triggers without being added to the result: the timer uses the capture time of the first frame in each confirmed change. Once present, a person must drop 0.10 below the threshold to count as gone (hysteresis). Results are approximate, not certified timing equipment, and are shown to 0.01 s.

How the timer works

The app waits until a person is detected in the zone, then arms itself. A confirmed disappearance starts the timer; a confirmed return stops it. If the page is hidden or the camera is lost mid-attempt, the attempt is discarded.
